## ✨ All

- Cleaned up heading titles/levels and field labels
- Increased clarity on instructions
- Diagram template/example filenames (in the /img folders) have '-template'/'-example' suffixes to differentiate from user created diagrams
- Diagram template/example images have watermark labels added
- Using [!TIP] quote block to highlight and delineate example diagrams/tables. During grading, these areas will be filtered out before the AI inference step.
- Artifacts with [Application/Component Name] (i.e. 4.x – 7.x) in the title will also ask for Relevant Central IDs (if applicable)
