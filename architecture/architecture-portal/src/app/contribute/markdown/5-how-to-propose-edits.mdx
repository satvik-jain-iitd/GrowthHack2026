# How to Propose Edits via the WYSIWYG Editor

You can easily propose changes to documentation pages using the built-in WYSIWYG (What You See Is What You Get) editor. Follow these steps to submit your improvements:

## 1. Click the "Edit Page" Button

Navigate to the documentation page you wish to update.
At the bottom of the page, click the **Edit Page** button. This will open the WYSIWYG editor.

> **Note:** If this is your first time editing, you'll be redirected to GitHub and asked to sign in and grant access to our application for authentication. Once authorized, you'll return to the editor and can continue making your changes.

## 2. Make Your Changes

Use the editor to update the content. You can format text, add lists, tables, and more. The preview tab lets you see your changes as they will appear.
When you're ready, click **Save**. You'll be prompted to confirm that you want to propose your changes. Confirm to create a pull request.

## 3. Confirmation and Pull Request Link

After submitting, you'll see a confirmation dialog with a link to your pull request on GitHub. Copy/save this link if you wish to track the status of your proposed changes.

> **Note:** Once your pull request is reviewed and merged, your changes will appear on the site within about 60 seconds. The page automatically refreshes its content every minute.

### Alternative: Edit Directly on GitHub

If all else fails, you can also use the **View Source** link on any page to go directly to the source file on GitHub and propose changes there.
