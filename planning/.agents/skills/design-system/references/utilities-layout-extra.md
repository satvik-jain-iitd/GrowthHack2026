# Responsive Display Utility Classes

Breakpoint-scoped display utilities from the `dls-max` stylesheet.

Available breakpoint suffixes: `-min-down`, `-xs-up`, `-xs-down`, `-sm-up`, `-sm-down`, `-md-up`, `-md-down`, `-lg-up`, `-lg-down`, `-xl-up`, `-xl-down`, `-max-up`

For static (non-responsive) display and layout classes, see [utilities-layout.md](utilities-layout.md).

---
