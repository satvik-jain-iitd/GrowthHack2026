# Responsive Spacing Utility Classes

Breakpoint-scoped margin and padding utilities from the `dls-max` stylesheet.

Available breakpoint suffixes: `-min-down`, `-xs-up`, `-xs-down`, `-sm-up`, `-sm-down`, `-md-up`, `-md-down`, `-lg-up`, `-lg-down`, `-xl-up`, `-xl-down`, `-max-up`

For static (non-responsive) spacing classes, see [utilities-spacing.md](utilities-spacing.md).

---

### `margin-1-` through `margin-4-` Variants

Pattern: `margin-{scale}-{side?}-{bp}` where scale is `1`–`4`, side is optional (`lr`, `tb`, `t`, `b`, `l`, `r`), and bp is any breakpoint suffix.

- `margin-1-min-down` … `margin-1-r-max-up` (same side/bp pattern as `margin-0-` above)
- `margin-2-min-down` … `margin-2-r-max-up`
- `margin-3-min-down` … `margin-3-r-max-up`
- `margin-4-min-down` … `margin-4-r-max-up`
