# Setting Up Resy OS on an iPad

Prior to using Resy in your restaurant, we recommend doing a quick initial set-up to customize your device. In this article, you'll find how to create custom Guest and Visit Tags, and how to turn on a few features that will help you manage your reservations smoothly.

**In this article**:

* Add Guest and Visit Tags
* Elapsed Seated Time
* Prompt to Assign Table After Booking an Unassigned Reservation
* Show Reservation Visit Notes
* Add Host Name to Accountability screen
* Remove Host Name from Accountability screen

---

  

Add Guest and Visit Tags

Guest Tags live on a guest profile indefinitely. For example, neighbor, gluten allergy, regular, etc. Visit Tags live on a unique reservation. For example, birthday, anniversary, etc.

To add Guest and Visit Tags:

1. Tap your restaurant name in the top-left corner.
2. Tap "Settings".
3. Tap "Tags".
4. Tap the “Guest Tags” or “Visit Tags” tab.
5. Tap "Create ___ Tag".

### Elapsed Seated Time

When seating a guest on the floorplan, you'll see the time the guest was seated at the table. Enabling the Elapsed Time feature will allow you to see the time elapsed on a seated reservation.

1. Tap your restaurant name in the top-left corner.
2. Tap "Settings".
3. Tap "Floorplan".
4. Toggle on "Show duration of seated reservations".

  
[[IMAGE: resyos-ipad-set-up__img02]]  
### 

### Prompt to Assign Table After Booking an Unassigned Reservation

You'll be prompted to assign the reservation to a table when this is toggled on.

1. Tap your restaurant name in the top left-corner.
2. Tap "Settings".
3. Tap "Reservations".
4. Toggle on "Prompt table assignment after booking unassigned reservation".

  

### Show Reservation Visit Notes

You'll see Visit Notes directly in the Reservation List when this is toggled on.

1. Tap your restaurant name in the top-left corner.
2. Tap "Settings".
3. Tap "Reservations".
4. Toggle on "Show Visit Notes on reservation list".

[[IMAGE: resyos-ipad-set-up__img03]]  

### Add Host Name to Accountability Screen

1. On the Resy OS app, start the process of booking a reservation by clicking the Booking Icon in the upper-right corner.
2. Once a guest has been selected, tap "Reserve".
3. From the Make Reservation screen, scroll to the Completed By section and tap "+ Add Name".
4. In the text box, add the employee's name and click "Add".

[[IMAGE: resyos-ipad-set-up__img04]]

### Remove Host Name from Accountability Screen

1. On the Resy OS app, start the process of booking a reservation by clicking the Booking Icon in the upper-right corner.
2. Once a guest has been selected, tap "Reserve".
3. From the Make Reservation screen, scroll to the Completed By screen.
4. Tap and hold the employee's name you would like to remove.
5. Tap "Remove".
