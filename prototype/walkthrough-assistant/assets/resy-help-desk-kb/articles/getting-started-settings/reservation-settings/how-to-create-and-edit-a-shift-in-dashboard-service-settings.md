# Shift Editor

You can create new shifts or make changes to your existing shifts in your Service Settings in the [Resy Dashboard](https://os.resy.com/portal/venues). Change hours, reservation availability, table access and pacing for breakfast, brunch, lunch and dinner shifts.

**In this article:**

* [Access Dashboard Service Settings](#part1)
* [Create a New Shift](#part2)
* [Edit an Recurring Shift](#part3)
* [Related Resources](#part3)

---

  

### Access Dashboard Service Settings

To create and edit a new shift, access the Dashboard Service Settings by:

1. Selecting "Service" from the left-hand menu.
2. Then, click on "Shift Settings" to open a weekly calendar showing the current shifts that you have active this week, in addition to any shifts that you have in place for future dates.

***Please note:****T**he login you use must have the correct permissions. To learn more about changing user permissions, click*[*here.*](https://helpdesk.resy.com/en_us/user-permissions-r1zCWDmU_)

  

---

### 

### Create a New Shift

1) Select "Service" from the left-hand menu and click on "Shift Settings".

2) Click the "New Shift" blue button in the top-right corner. The shift creation tool will walk you through the steps to setup all aspects of this new shift with helpful tips along the way.

* Shift Basics
* Service Settings
* Availability
* Reservation Settings
* Custom Policies
* Click "Update Shift" to complete shift creation

---

  

### Edit a Recurring Shift

1. Once you're in "Shift Settings", click the menu icon (three dots button) in the top-right corner of a shift.
2. A drop-down menu with the options "Edit Shift", "Copy Shift" or "Delete Shift" will open.
3. Select "Edit Shift" to open shift details where you can make the necessary adjustments.

***Please Note:****Editing a shift will edit the shift for **all days this shift is active**. To make edits to specific days, please check out:*[*"How do I make a Single Day Edit in the Resy OS Dashboard?"*](https://resy.kustomer.help/en_us/how-to-make-a-single-day-edit-in-the-dashboard-service-settings-rJf6bD7IO)

***Tip:** If your new shift is only slightly different from an existing shift, it can save time to copy the existing shift and make a few adjustments than to start from scratch!*
