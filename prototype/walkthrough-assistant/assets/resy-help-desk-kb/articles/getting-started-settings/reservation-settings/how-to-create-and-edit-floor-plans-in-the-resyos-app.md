# Floor Plan Edits in ResyOS and on Web

You can make changes to the tables on your floor plan or create a new floor plan from your computer or iPad in the Resy OS app. 

| **Please note**: You can adjust a Single Day Floor Plan on Resy OS. Learn more about single day floor plan edits [here.](https://helpdesk.resy.com/how-to-update-a-floor-plan-for-a-single-day-H1z3v7Ud) |

### How to Add a Floor Plan on Resy Dashboard

1. Log on to the [Resy Dashboard](https://os.resy.com/portal/venues) using Chrome.
2. Click the **"Venue"**from the left-hand menu options.
3. Click **"Floor Plans"** from the drop-down menu options.
4. Click "New Floor Plan"**. [[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img01]]**
5. Click **Add Table** to build a new Floor Plan from scratch and enter the following details: 
	* **Table ID**: The Table ID must be unique. i.e., you can only have one table 20 on your floor plan. Tap the Table ID field to edit.
	* **Table Type**: The Table Type should reflect the actual seating type of the table (Dining, Bar, Patio, High Top).
	* **Min/Max Seats**: Input the minimum and maximum capacity for the party size that will be allowed to book and be assigned to this table.
	* **Shape**: Select the shape of your table.[[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img02]][[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img03]]
6. Click **Save** when done.

| **Pro Tips:*** If you change the Table ID (Table Number) on existing tables, the existing reservations will become **unassigned**and will need to be manually re-assigned. * If you unknowingly unassigned reservations, you can revert the Table ID to the original ID and Reservations will re-assign to original Table ID assignment. * All new tables created will be available in-house by default. To update Availability for a new table to 'online' or 'walk-in' status on the shift, follow the instructions here [Availability Updates](https://helpdesk.resy.com/en_us/how-to-manage-shift-availability-rJk3ZDQ8_). * You must add your Floor plan to the shift for it to be active. View detailed instructions for activating your floor plan here, [Activating a New Floor Plan](https://helpdesk.resy.com/en_us/how-to-activate-floor-plan-and-edit-table-availability-in-dashboard-for-a-shift-BJEnbPXUd). * You can use the Table Type as the Reservation Display Name or create a Custom Reservation Display Name. View detailed instructions here on customizing your reservation names, [Reservation Names vs Table Type](https://helpdesk.resy.com/en_us/reservation-names-r1fd_spaY). |

### **Edit an existing Floor Plan**

1. Log into the [Resy Dashboard](https://os.resy.com/portal/venues) using your credentials.
2. Select **"Venue"** from the left-hand menu options.
3. Select **"Floor Plans"** from the drop-down list.
4. Click the pencil icon to the left of the ellipses.
5. Click on the table you'd like to make edits on.

[[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img04]]

| You can duplicate tables and add decor (shapes) here as well. Click **Add Decor** or **Duplicate** to accomplish this! |
| --- |

### 

### **Create and Edit Table Combinations**

1. Once you are in Edit mode, click the first table that is part of the Combination.
2. Once the first table is selected, press and hold the **Command** (Ctrl if you are using a Windows) button on your keyboard to select additional tables.
3. Select "**Create Combo"** in the top left once all tables in the combination have been selected.
4. Select the Table Type, and Min/Max seats for the combination.[[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img05]]
5. Click "**Save"** when done editing.

### How to Add a Floor Plan on ResyOS

1. Tap the restaurant name in the top left corner > Select **Edit Floor Plans** from the dropdown menu.  [[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img06]]
2. Select the floor plan title at the top of the Floor Plan Editor to open the Manage Floor Plans window. From there, you can do the following:
* **Build a New Floor Plan from scratch:**Tap the plus    icon.
* **Edit the name of an Existing Floor Plan:** Select any of your existing floor plans and tap the pen and paper   icon to rename.
* **Copy a Floor Plan:**Tap pages   icon for a quick way to make a copy of an existing floor plan and make minor edits for holidays/events.
* **Delete the Floor Plan:**Select the floor plan and tap trash icon to delete and remove a floor plan completely.

[[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img07]]  

| **Pro-tips**: * If the iPad is locked, rotated, locked by inactivity, or switches apps, all unsaved changes to your floor plan will be lost. Please lock the "rotate screen" function before making floor plan edits. * If you don't see the Edit Floor Plans option on the menu in the ResyOS app on your iPad, you may need to update your user permissions. This article explains how to make this update, [Add User and Password Permissions for Users](https://helpdesk.resy.com/en_us/user-permissions-r1zCWDmU_). |

### Create a New Table on ResyOS

1. Tap and drag the white shapes at the bottom of the floor plan to create a new table. The new table will appear directly on the floor plan and can be dragged to the desired location and resized by pinching or expanding.
2. The Table Details side panel will be open for you to enter the following details:
* **Table ID:**The Table ID must be unique. i.e. you can only have one table 20 on your floor plan. Tap the Table ID field to edit.
* **Table Type:**The Table Type should reflect the actual seating type of the table (Dining, Bar, Patio, High Top).
* **Min/Max Seats:**Input the minimum and maximum capacity for the party size that will be allowed to book and be assigned to this table.

### Edit a Table on ResyOS

1. Tap the floor plan name in the top center of screen and select the floor plan you want to make edits to.
2. Tap on a table on the floor plan to bring up the Table Details in the left side panel. Edit Table ID, Table Type, and Min/Max Seats.
3. Tap and drag tables to new locations. Tap and drag blue dots to resize the shape. Use the orange dot to rotate the shape.
4. Select **Save** in the bottom-right corner to complete floor plan edits

[[IMAGE: how-to-create-and-edit-floor-plans-in-the-resyos-app__img09]]

## 

### Create and Edit Table Combinations on ResyOS

1. Tap the floor plan name in the top center of screen and select the floor plan you want to add the combination tables.
2. Tap **Combinations**tab at the top of the table details to see a list of current combinations.
	* Tap an existing combination on the list to edit the table details.
3. To create a new combo, tap **Create Combo** at the bottom of the panel.
4. Tap all the tables on the floor plan you'd like to combine and add the Table Type, and Min/Max Seats in the left side panel.
5. Tap **Done** to complete the combination and another.
6. Tap **Save** in the bottom right corner to complete floor plan edits.
