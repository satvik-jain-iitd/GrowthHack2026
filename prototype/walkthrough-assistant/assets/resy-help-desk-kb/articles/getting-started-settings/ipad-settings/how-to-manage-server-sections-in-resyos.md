# Manage Server Sections in Resy OS

#### Add Server Names, Assign, & Remove Servers, and Manage Server Sections. Track each server's table and cover count, see who was seated last and who is next up.

Resy OS now allows you to manage your server section and track each server’s active, future, and done covers in real time. You'll see a running tally of tables and covers, sorted by next up or most recently seated. 

### **Add Server Names**

1. From floor plan view, tap the server hand icon below the date at the top of the screen.
2. Tap “+” in the top left-corner of the Server Section Panel.
3. Enter the First Name and Last Name (optional) of the Server.
4. Tap "Add Server".

### **Assigning a Server to a Section**

1. From floor plan view, tap the server hand icon below the date at the top of the screen.
2. Find the server that you want to assign to tables.
3. Tap the “>” to the right of their name.
4. Tap the tables you want to assign to the server.
5. Tap "Save Assignment Updates".

### **Deleting a Server**

1. From floor plan view, tap the server hand icon below the date at the top of the screen.
2. Tap the server’s name.
3. Tap "Edit".
4. Tap "Delete Server".

### **Manage Server Rotation & Stats**

1. From floor plan view, tap the server hand icon below the date at the top of the screen.
2. Tap the server’s name.

 

Features: 

* Choose which server will be the "Closer".
* View covers (Active, Future, and Done) in real time.
* View tables (Active, Future, and Done) in real time.
* View tables by party size and last seated per Server.
* View "Next to Seat" Server in Server Sections panel.
