# Add User and Password Permissions for Users

**Learn to add, edit, remove and manage all users and logins.** If you don’t want the user to make any edits to the Settings within your dashboard, you don’t need to give them any. They'll still be able to view the Analytics portion of the Dashboard.

## Add, Edit, or Remove Users in 'Users' section

***Please note:** Only users with the permission to '"Manage Users" will have access to this section of the Resy Dashboard. Learn about user permissions below. Set up distribution lists for reports for each login.*

First, you'll log in to the Dashboard using Chrome

1. Log in to the ResyOS Dashboard [here](https://os.resy.com/portal/venues).
2. Click "Accounts" from the left side menu.
3. Once you click on "Users" menu from the left side menu, you’ll see a list of all the users who have a username and access to your system. For each user, you’ll be able to see their Name, Email Address, Job Title, Permissions given, and whether or not Password Protections are enforced for the user.  
[[IMAGE: user-permissions__img01]]

### Add A New User

1. To create a new user, click the "Add User" button in the top-right corner
2. Enter the employee name and email address, then select a job title from the drop-down menu. The job title selection will help you organize your users and will let our Support team know who they're chatting with when contacting us for assistance.
3. Assign the "User Booking & Settings Permissions."*Please note: All Booking Permissions include reservations with a price or cancellation policy associated with them, requiring credit card details to be taken during the booking process. If your restaurant doesn’t have any prepaid reservations or cancellation policies, then you don’t need to worry about these permissions.*
+ **Book without Payment** - This permission allows the user to opt out of inputting a guest's credit card information when booking in-house for a guest on a table with a cancellation fee.
+ **Charge Cancellation Fee** - This permission allows the user to charge a cancellation fee for guests who violate the policy. Click [here](https://resy.kustomer.help/en_us/how-do-i-charge-a-cancellation-or-no-show-fee-HJQXfP7Lu) to learn how to add a credit card to a reservation and charge cancellation fees.

[[IMAGE: user-permissions__img02]]  

Once you've added new users, you'll see their name listed in the restaurant user list with an "Invited" status. At this time, the user is sent an email confirming the account is active. Users need to click the link in the email to reset their passwords. Once they've set their password, their status will no longer be "Invited".

### **Edit An Existing User**

Click on the three dots on the right of the user to **edit their information and permissions or deactivate their account therefore removing all access.**

## User Permissions

**Booking Permissions**

* **Book without payment**- gives the user the ability to skip adding credit card payment information to reservations with prepaid/cancellation policies.
* **Charge cancel fee**- gives the user the ability to charge a guest who late cancels or no shows a cancellation fee, if there is a cancellation policy attached to the reservation.

**Update Settings Permissions**

* **Update venue details and transactions settings** - gives the user the ability to update the Venue and Transaction settings in the online dashboard
* **Create exclusive groups** - gives the user the ability to create [Exclusive Groups](https://helpdesk.resy.com/en_us/how-to-use-exclusive-online-booking-channels-BkihvQIO) (available for Platform 360 and Full Stack restaurant partners)
* **Create and edit floor plans on the web dashboard** - gives the user the ability to create and edit your floor plan in the online dashboard
* **Update shifts** - gives the user the ability to edit your shifts in the online dashboard
* **Single-day changes** - gives the user the ability to create Single Day Edits in the calendar in the online dashboard or on the grid view in ResyOS
* **Guest communications** - gives the user the ability to edit the timing and verbiage of your automated guest emails and text messages (available for Platform 360 and Full Stack restaurant partners)
* **Manage users** - gives the user the ability to add new users and edit the permissions of users
* **Set and update tax rates** - gives the user the ability to set and update your tax rates in your Transaction Settings

**Password Protections Enforced**

* **Enforce password protection** - if turned on, the users login will not be able to bypass any Password Protections you have set up and they'll be prompted to enter the pin. If turned off, the user's login will not be prompted to enter the pin for any Password Protections you have set up.

## Password Protections

**What is it?**When performing an action that is password protected, users will be prompted to enter the password. If entered incorrectly, the action will fail. You can turn this off to allow the user to bypass the need for a password when logged in.

Only users with the permission to "Manage Users" will have access to manage password protections. The following actions can be **password protected:**

* Creating unassigned reservations
* Booking and assigning reservations to in-house inventory
* Closing and opening days and shifts
* Adding and removing blocks on tables
* Editing floor plans and tables on the ResyOS app
* Disabling online reservations for a shift
* Single-day availability changes
* Adding or removing VIP tags
* *Unassigning Global Dining Access slots when overlapped (if applicable)*

## Resetting your Password

1. Go to the Dashboard login page [here](https://os.resy.com/portal/venues)
2. Click on “Forgot Password”

If you’re already logged into the Dashboard and want to change it to something else:

1. Click on your name in the upper right-hand corner
2. Click on Reset Password

**Both ways will trigger a password reset email to be sent!**
