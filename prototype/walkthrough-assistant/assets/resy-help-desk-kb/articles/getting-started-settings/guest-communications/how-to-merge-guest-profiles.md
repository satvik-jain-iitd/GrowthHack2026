# How to Merge Guest Profiles

**How to Merge Guest Profiles**

You will need to merge guest profiles if a guest has multiple profiles within Resy. Merging the profiles will keep all guest visit information in one place so that it's easier to access. 

**Please note:** App User profiles cannot be merged. When a guest creates their profile through [Resy.com](https://resy.com/) or the Resy App, their information is protected and can only be edited by the guest or [Resy Support](https://helpdesk.resy.com/en_us/how-to-contact-resy-support-Bk_JGP7Lu). 

Below are the ways that you can merge guest profiles:

**Tapping the Blue Exclamation Point**

1. On the guest profile, tap the exclamation point next to the guest’s mobile number or email address.
2. A “Duplicate Phone Number” message is going to pop up. Confirm that the guest information in that pop up is correct, and if so, click “**Merge Guests.**”
3. Select the profile name and mobile number that you would like to appear on the guest’s profile once merged.
4. Tap "Preview Profile."
5. Tap "Merge Guest."

**Tapping "Merge Guest" from the Menu**

1. On the guest profile and click the 3 dots to the right of the guest’s name.
2. Tap "Merge Guest."
3. Search and select the profile that you would like to merge with.
4. Select the name, phone number and email address that you would like to appear on the profile.
5. Tap "Preview Profile."
6. Tap "Merge Guest."
