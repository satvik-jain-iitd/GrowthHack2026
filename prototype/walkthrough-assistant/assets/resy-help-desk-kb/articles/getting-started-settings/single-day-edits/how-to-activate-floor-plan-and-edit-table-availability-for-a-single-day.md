# Single Day Edits to Floor Plan and Availability

Activate a new or existing floor plan and adjust table availability as needed for special occasions, buy-outs, or holidays with a Single Day Edit.

**Please note**: If you don't see the option for “Service” in the dashboard left-hand menu, you can adjust user permissions to allow access to “Update Shifts”. 

  

---

## **Activate a Floor Plan & Edit Table Availability**

For a special floor plan to show on a single day, you'll need to activate the floor plan on the day(s) and adjust the availability as needed.

To activate a floor plan for a single shift, first you'll log on to the [Dashboard](https://os.resy.com/portal/login) using Chrome:

1. Click “Service” from the left-hand menu, then “Calendar”.
2. Click the date you want to edit then “Single Day Edit” and select “Shift”.
3. Select “Step 2 Service Settings” and “Floor Plans”.
4. Click “Edit” next to Active Floor Plans.
5. Toggle on the Floor Plan you want active for the shift.
6. Click “Save”.
7. Continue to “Step 3 Availability”.
8. Select “Online”, “In-House”, or “Walk-in” **or** select “Customize Availability by Time” to create mixed availability on certain times and tables.
9. Select “Done” and then “Update Shift” to save changes.
