# Activating a New Floor Plan

You can activate a new or existing floor plan in a base shift and adjust table availability as needed.

**Please note**: If you don't see the option for “Service” on the left-hand menu, you can adjust user permissions to allow access to “Update Shifts”. 

---

## **Activate a Floor Plan & Edit Table Availability**

In order for a floor plan to show in All Base Shifts, you'll need to activate the floor plan in the shift and adjust the availability as needed.

First, you'll log on to the [Dashboard](https://os.resy.com/portal/login) using Chrome:

1. Click “Service” from the left-hand menu options.
2. Click "Shift Settings" from the drop-down menu options.
3. Click the three dots on the top-right corner of the shift you wish to edit and select “Edit Shift”.
4. Select “Step 2 Service Settings” and “Floor Plans”.
5. Click “Edit” next to “Active Floor Plans”.
6. Toggle on the floor plan you want to use.
7. Click “Save”.
8. Continue to “Step 3 Availability”.
9. Select “Online”, “In-House”, or “Walk-in”, **or**select “More Customization” to create mixed availability on certain times and tables.
10. Select “Update Availability” and then “Update Shift” to save changes.
