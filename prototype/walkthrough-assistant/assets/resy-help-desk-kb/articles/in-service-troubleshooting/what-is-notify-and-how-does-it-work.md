# Notify Feature

You can think of 'Notify' as a future waitlist, where guests can add themselves to a list and be alerted when a table opens up that meets the specifications they were looking for (date or time range)

**In this article:**

* Access 'Notify'
* How does 'Notify' work?
	+ During Service
	+ [Resy.com](//Resy.com)
	+ Resy App
	+ Priority Notify

  

---

### 

### Access Notify

On the left hand panel of the ResyOS Dashboard, 'Notify' is located above the 'Waitlist' tab. 

  

---

### 

### How does 'Notify' work?

**During Service:**Once you add a guest to the 'Notify' list, they will receive an email or app push notification when a table opens up at on the date and time range they are interested in dining.

1. To add a guest to your Notify List, tap on the ( + ) symbol on the list header.
2. The 'Notify' module will open up where you can select the date and time range a guest is interested in dining with you
3. Enter the guest information. *Please note you will need an email address associated with the guest in order to save them to your Notify list.*

[**Resy.com**](//Resy.com) Guests can add themselves to the 'Notify' list via [Resy.com](//Resy.com)

* The 'Notify' button appears underneath the booking calendar. Guests will tap on the 'Notify Me' button and be prompted to enter the time range they would be interested in.

**Priority Notify:** Global Dining Access (GDA) provides eligible Card Members with Priority Notify, which allows GDA members to set notifications to be in the first group notified when tables become available before they’re made available to other Resy users. This feature is available for all restaurants on Resy, regardless of participation in the Global Dining Access program.
