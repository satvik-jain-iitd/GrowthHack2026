# Guest Profile Updates

You can update a guest's profile name in Resy OS only if the profile was created by the restaurant. If the guest created their own profile from [resy.com](http://resy.com/) or the Resy App, you will not be able to edit their name. [Learn how to update a guest's phone number](https://helpdesk.resy.com/en_us/guest-wrong-number-BkjGmjB2c)[.](https://helpdesk.resy.com/en_us/guest-wrong-number-BkjGmjB2c)

**In this article:**

* Editing a Guest's Name Created by the Restaurant
* Editing a Guest's Name Created by the Guest

 

---

## **Editing a Guest's Name Created by the Restaurant:**

1. Find the guest's profile either from your Guest Book or from an upcoming reservation.
2. Once in the Reservation profile, tap the three vertical dots to get the dropdown menu.
3. Select 'Edit Guest Name' and then you will be prompted to update the First or Last Name for this guest.
4. Hit 'Update Name' when done to save your changes.

### Editing a Guest's Name Created by the Guest:

The guest can edit their own name from [Resy.com](http://resy.com/) or the Resy App.

  

### From [Resy.com](http://resy.com/):

1. Tap the profile photo icon in the top right
2. Tap 'Profile'
3. From there, the guest can edit their name, phone number, email, photo, and Resy Bio.

[[IMAGE: how-to-edit-a-guest's-name__img04]]  
### From the Resy App:

1. The guest will want to tap their profile photo icon in the top left corner
2. Tap 'Edit guest profile'
