# Right Phone Number, Wrong Guest?

Resy uses phone numbers as a unique identifier so a phone number can only be tied to **one guest**. If the wrong guest's name is tied to a phone number, use the “Right number, wrong guest?” flow when booking a reservation. 

In this article:

* How to use the “Right number, wrong guest?” flow

---

  

## How to use the “Right number, wrong guest?” flow

  

1. In the Resy OS Dashboard, click “New Reservation” in the top-left corner.
2. Select your Venue > Party Size > Reservation date and time.

  

From the "Add Guest" section on the right side, after entering the phone number click on “Right number, wrong guest?”

Create a new Guest Profile with the same phone number through this flow.
