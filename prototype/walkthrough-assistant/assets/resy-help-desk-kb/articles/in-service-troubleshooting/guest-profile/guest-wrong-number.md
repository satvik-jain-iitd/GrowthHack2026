# Update Phone Number in Guest Profile

If there's an incorrect phone number on a guest profile, follow the instructions here to edit. 

**Please note:**Editing a Guest Profile through web booking is only available for partners with Platform 360 Plan. 

**In this article:**

* [ResyOS App](#part1)

---

  

## ResyOS App

If the guest has an App User profile, you'll have to reach out to Support for minor changes. If the request is to completely change the current phone number, for security of the guest's account, please advise the guest to reach out to our Diner Support team directly at [help@resy.com](mailto:help@resy.com) for assistance.

If the guest does not have an App User profile, you will have to input a fake phone number until you're able to receive the correct phone number from the guest. 

To edit a guest’s phone number on the Resy OS App during the booking process:

1. Click on your restaurant name and select “Guest Book”.
2. Search for the guest profile and edit phone number.
