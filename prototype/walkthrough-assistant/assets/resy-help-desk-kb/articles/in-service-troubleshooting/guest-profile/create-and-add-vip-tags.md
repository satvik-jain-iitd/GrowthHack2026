# Create and Add VIP tags

VIP tags are a convenient way to identify specific guests and can be added to a guest profile from the dashboard or Resy OS app.

In this article:

* [How to add a new VIP Tag (ResyOS App)](#part1)
* [How to add a VIP Tag to a guest’s profile](#part2)
* [How to add a VIP Tag to a guest’s profile from the Guestbook](#part3)
* [How to add a VIP Tag to a guest’s profile (ResyOS Dashboard)](#part4)

---

  

**How to add a new VIP Tag (ResyOS App)**

1. Tap your venue’s name on the upper left-hand corner.
2. Tap “Settings".
3. Under “Group Settings,” tap “VIP".
4. Tap “Add New".
5. Enter the “VIP Tag Name".
6. Tap “Create VIP Tag".

---

  

**How to add a VIP Tag to a guest’s profile**

1. Tap the “•••” to the right of the guest’s name in their profile or reservation.
2. Tap “Change VIP Status".
3. Tap the appropriate VIP tag for the guest and add a note if desired.

---

  

**How to add a VIP Tag to a guest’s profile from the Guest Book**

1. Tap the venue's name in the upper left-hand corner.
2. Tap “Guest Book” in the dropdown menu.
3. Search for the guest by name, email, or phone.
4. Tap the guest’s name when it appears.
5. Tap the “•••” to the right of the guest's name.
6. Tap “Change VIP Status".

Tap the appropriate VIP tag for the guest and add a note if desired.

---

  

**How to add a VIP Tag to a guest’s profile (ResyOS Dashboard)**

1. Log in to the [Resy OS Portal](https://os.resy.com/portal/).
2. Click “"Reports".
3. Click “Reservations”.
4. Toggle the guest’s reservation date.
5. Click the “•••” to the far right of the reservation.
6. Click “Change".
7. Click the “•••” just above and to the right of the guest's name.
8. Click “Change VIP Status".
9. Click the appropriate VIP tag for the guest and add a note if desired.

**Please note**: VIP tags can also be added by selecting the “•••” when booking new or changing reservations on both the OS app, as well as when booking new reservations via Dashboard.
