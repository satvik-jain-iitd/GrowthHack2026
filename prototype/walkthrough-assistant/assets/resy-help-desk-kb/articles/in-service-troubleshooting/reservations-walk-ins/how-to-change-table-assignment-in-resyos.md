# Change a Table Assignment in Resy OS

Change a table assignment for a party from the floor plan view and from the timeline view in Resy OS.

Resy maximizes turns per table by pre-assigning your reservations to tables. Table assignments can be changed from either the floor plan or the timeline view. Follow the instructions below.

**Option 1: Changing a Table Assignment from the Floor Plan View**

1. Find the reservation on the booked list located to the left of the floor plan.
2. Tap the table number to the right of the party size on the booked list.
3. This will illuminate any tables that can accommodate the reservation party size. You can still select any table you'd like.
4. Tap the table you'd like to assign to the reservation. If your party size is larger than the table size, you'll be prompted to select more than one table. Click “Done” at the top once you've selected enough tables.

[[IMAGE: how-to-change-table-assignment-in-resyos__img01]]## 

**Option 2: Changing a Table Assignment from the Timeline View**

1. Hold your finger down on the reservation you'd like to move.
2. Drag the reservation to the table of your choice.
3. Release your finger.

[[IMAGE: how-to-change-table-assignment-in-resyos__img02]]  

**Option 3: Move/Swap a single reservation from one table to another in Floor Plan view**

1. Tap on a table to view all reservations.
2. Hold on the single reservation to move in the pop-up screen.
3. Drag the single reservation to the table of your choice.
4. Release your finger.
5. If the alternate table has an overlapping reservation, you are presented with the option to swap or overbook.

Please note that swapping a reservation that matches both time and party size exactly with the reservation it is being swapped with will not prompt for approval.

**Option 4: Move/Swap all reservations from one table to another in Floor Plan view**

1. Tap on the table to view all reservations.
2. Hold on "X Reservations" header (rather than individual reservation).
3. Drag all reservations to the table of your choice.
4. Release your finger.
5. If the alternate table has overlapping reservations, "Swap All Reservations" pop-up is shown.
6. Tap “Swap all Reservations”.
