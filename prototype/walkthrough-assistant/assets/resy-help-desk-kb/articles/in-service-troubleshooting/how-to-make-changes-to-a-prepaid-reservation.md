# Prepaid Reservation Changes

Update payment and make changes to a paid reservation. [Learn more about Prepaid Reservations](https://helpdesk.resy.com/en_us/adding-a-prepaid-policy-H139rKJLF).

**Please note:** You'll make changes to a prepaid reservation in the Resy OS app.   
Via Web Booking, the initial prepaid charge will always be refunded if an edit is made to a Prepaid reservation. You will need to rebook with payment if making changes on Web Booking.

## **How to Change a Prepaid Reservation?**

1. Go to the Reservation Profile and tap the 3 dots on the upper right-hand corner.
2. Select “Rebook Reservation”.
3. Select the new party size, date, and/or time.
4. Tap “Add Payment” and select the guest credit card on file.
5. Tap “Change”.
6. Select the person this will be “Completed By”.

**Please note**: If the reservation is still within the refund window, the guest will be automatically refunded for the original reservation and charged for the new booking. If they are outside of the refund window*,**you will need to refund them in your Stripe Dashboard. Click*[*here*](https://helpdesk.resy.com/en_us/stripe-refunds-SkOy9nSMh)*to view our Stripe Refunds article for instructions on how to refund a guest in Stripe*. 

## [[IMAGE: how-to-make-changes-to-a-prepaid-reservation__img01]]**How to Change the Party Size for a Prepaid Reservation?**

1. Go to the reservation profile and tap the 3 dots on the upper right-hand corner.
2. Select “Rebook Reservation” and select the new party size.
3. Tap “Add Payment” and select the Guest profile on file.
4. Tap “Change”.
5. Select the person this will be “Completed By”.
6. Toggle on “Refund Payment”.

Tap “Confirm Change” to re-charge the guest for the new party size. This will complete the change in party size and the guest will receive a new confirmation email.

**Please note:** When you change the party size of a prepaid reservation this will trigger a new charge for the price of the new party size. In order to avoid creating a double charge, you’ll want to opt to **refund the original payment** when making the change.

## [[IMAGE: how-to-make-changes-to-a-prepaid-reservation__img02]]**How to Change the Time or Date for a Prepaid Reservation**

**Please note**: You do not need to refund the guest when changing the date or time of a prepaid reservation because you will “Book Without Payment”.

1. From the Reservation Profile, tap the 3 dots on the upper right-hand corner.
2. Select “Rebook Reservation”.
3. Select the date or time.
4. If a credit card is selected, click the last 4 digits of the credit card and click the credit card again to **deselect**it. When you deselect the credit card, you should see "Add Payment" on the bottom right-hand corner.
5. Tap “Change”.
6. Select “[Book without payment](https://resy.kustomer.help/en_us/how-to-bypass-a-credit-card-requirement-BkeQMvmId)”.
7. Select the person this will be “Completed By”.
8. Tap “Confirm Change”.

[[IMAGE: how-to-make-changes-to-a-prepaid-reservation__img03]]

  

If a guest wants to move a booking for the same party size to a new date or time, you’ll want to change the reservation to the new chosen date and time and select “Book without payment”. If you do not book without payment, Resy OS will charge the guest a second time for the change. Therefore, booking the change without payment leaves the original charge intact while not charging the guest a second time.
