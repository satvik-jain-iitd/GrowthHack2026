# Single Day Table Availability Updates in Resy OS

Quickly edit your table and reservation availability from the timeline view on your iPad for a specific shift.

**How to edit a specific block of time on a table for a single shift**

1. Navigate to the timeline view.
2. Choose the date and shift that you would like to edit.
3. Choose the 15-minute block of time you would like to edit.
4. Tap and hold on that block to bring up the action icons.
5. Drag up to select the availability icon.

[[IMAGE: how-to-make-single-day-edits-to-table-availability-in-resyos-app__img01]]  

Next, the side panel will pop-out and you can choose the details for editing.

6. Select the start and end time you'd like to edit on the table.
7. Select the availability you would like to apply (i.e., online, in-house or walk-in).
8. When you select the availability, you’ll see the times that you have selected highlighted in blue on the timeline as preview.
9. Tap the "Update Availability" button to save your changes.

[[IMAGE: how-to-make-single-day-edits-to-table-availability-in-resyos-app__img02]]  

**How to edit a specific block of time for all tables for an entire shift**

1. Navigate to the timeline view of the date and shift that you would like to edit.
2. Tap and hold on the time you would like to change from the top of the timeline view.
3. A side panel will open that will allow you to choose the details for editing and all tables for the selected time will be auto-selected for editing.
4. Tap to expand the start and end time to edit all tables for a set period of time.
5. Select the availability you would like to apply (i.e., online, in-house or walk-in)
6. When you select the availability, you'll see the edited availability icon highlighted in blue on the timeline.
7. Tap the “Update Availability” button to save your changes.

**Please note**: If you would like this edit to also affect table combinations, you must make sure your table combinations are viewable on the timeline. You can do this by tapping the three vertical buttons icon in the upper right corner of the timeline view and selecting “Show Table Combinations”.

[[IMAGE: how-to-make-single-day-edits-to-table-availability-in-resyos-app__img03]]  

**How to edit availability on a specific table for the entire shift**

1. Choose the table number you would like to edit.
2. Tap and hold on that table number to bring up the action icons.
3. Drag up to select the availability icon.

[[IMAGE: how-to-make-single-day-edits-to-table-availability-in-resyos-app__img04]]A side panel will open and the table selected will be pre-populated with the start and end time of the full shift.

4. Select the availability you would like to apply (i.e., online, in-house or walk-in).
5. When you select the availability, you'll see the edited availability icon highlighted in blue on the timeline.
6. Tap the update availability button to save your changes.

[[IMAGE: how-to-make-single-day-edits-to-table-availability-in-resyos-app__img05]]  

**Please note: All single day availability edits made in Resy OS from an iPad** will **not** currently show in the online dashboard calendar view with the purple highlight bar indicating the shift has been edited. It will **always** show accurate availability under the customize availability view when making a single day edit from the Dashboard.
