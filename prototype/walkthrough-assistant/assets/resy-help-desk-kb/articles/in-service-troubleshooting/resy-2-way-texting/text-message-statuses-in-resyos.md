# Text Message Icons

This article will walk you through identifying the status of text message conversations on your reservation list, waitlist and notify list. To review the standard text message language and timing, click [here](https://resy.kustomer.help/en_us/standard-resy-automated-sms-content-S110vQIu).

You can identify the status of your text messages in Resy OS by the color of the chat bubble icon that appears on the guest's reservation, waitlist or Notify profile.

[[IMAGE: text-message-statuses-in-resyos__img01]]

## 

## **Chat Bubble Key**

### **Please keep in mind that text messages may not include any content that can be considered promotional such as offers or****other marketing messages.**

 

#### **Grey Chat Bubble**

There is an active text message conversation with no new messages from the guest.

 

#### **White Chat Bubble**

There is an active text message conversation with a new unread message from the guest. The chat bubble icon will turn grey once the text message has been viewed.

#### 

#### **Red Chat Bubble**

There is an active text message conversation where one or more of the text messages were not successfully delivered. Some best practices for handling undelivered text messages are listed below.

### 

### **Undelivered Text Messages**

The most common reasons for undelivered text messages are:

* The number provided is a landline and cannot be texted.
* The number provided is invalid/incorrect.
* The guest is unsubscribed from receiving text messages from Resy.
* The guest's number is the correct mobile number but due to connectivity issues, the message did not go through.

 

[[IMAGE: text-message-statuses-in-resyos__img02]]

For **all** undelivered text messages, we recommend calling to confirm directly with the guest and manually adjusting the reservation status to “confirmed” in Resy OS. This will help reduce no-shows and discourage last minute cancellations. Consider the following actions to reduce the number of undelivered text messages in the future:

* **The number provided is invalid** - We recommend reaching out to the guest to update their profile with the correct mobile number.
* **The guest is unsubscribed from receiving text messages from Resy** - Instruct the guest to reply “start” to any past automated text message from Resy to resubscribe if they'd like to start receiving these messages again.
* **The guest's number is the correct mobile number but due to connectivity issues, the message did not go through** - We recommend checking your internet connection and attempting to send the message again. Tapping the “!” icon on the message will **not** trigger an automatic resend like in iMessage.
