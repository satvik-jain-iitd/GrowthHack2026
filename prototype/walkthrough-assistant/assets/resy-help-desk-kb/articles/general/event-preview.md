# Previewing your Event Before It's Live

# Event Preview

This feature gives you the ability to preview how your event will look for guests before setting it live. 

  

You'll have the ability to: 

* See a preview of how your event will appear to consumers on the web and booking widget.
* Toggle between previewing the event and editing the event content.
* Generate a preview link that can be shared with others (i.e. managers for approval).

In the flow of either creating an either an [Assigned Seating](https://helpdesk.resy.com/en_us/how-to-create-an-assigned-seating-event-rJ5FbDmUu) or [General Admissions](https://helpdesk.resy.com/en_us/how-to-create-a-general-admission-event-ByNFbwm8u) event, you'll see the Event Preview feature when you get to the "Ticket Settings" step. 

In the "Ticket Settings" step you'll:

1. Create your Ticket Types.
2. Under "Quantity" enter the minimum and maximum number of tickets a guest can reserve.
3. Under "Off-Market Time" enter when you'd like booking for the event to go off-line.

From there, you'll see "Preview**"** and "Save Draft" in blue on the bottom left.

[[IMAGE: event-preview__img01]]

***Please Note******:** You'll be able to preview your event from any step once you've completed the "Ticket Settings" step.*

The first time you Preview an event, you'll get a pop-up message that says to "Please save a draft before previewing". After the first time this pop up is received, selecting "Preview" will also automatically save the latest draft version of the event.[[IMAGE: event-preview__img02]]

  

You'll then click "Save Draft & Preview" and you'll be taken to a preview page of the event. [[IMAGE: event-preview__img03]]

***Please Note****: The Preview page will need to be refreshed to see the most recently saved version of the draft event.*

Once on the preview page, you can click "Copy Preview Link" if you'd like to send a link to this preview page to a member of your staff to view before going live.
