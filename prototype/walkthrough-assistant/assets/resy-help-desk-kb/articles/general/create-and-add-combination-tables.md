# Create and Add Combination Tables

You can combine multiple tables in your floor plan for large parties by creating combination tables from your computer or iPad in the ResyOS app. 

| **Please note**: You can adjust your floor plan for a single day in ResyOS. Learn more about single day floor plan edits [here](https://helpdesk.resy.com/how-to-update-a-floor-plan-for-a-single-day-H1z3v7Ud). |
| --- |

  

**In this article:**

* Create and Edit Table Combinations in the ResyOS App
* Create and Edit Table Combinations on Resy Dashboard

---

### **Create and Edit Table Combinations in the ResyOS App**

1. Tap the floor plan name in the top center of screen and select the floor plan you want to make edits to.
2. Tap **"****Combinations"** tab at the top of the Table Details to see a list of current combinations and tap an existing combination on the list to edit the Table Details.
3. Tap **"Create****Combo"** at the bottom of the panel to add a new combination.
4. Select a new combination by tapping all the tables on the floor plan you'd like to combine and adding the Table Type, and Min/Max Seats in the left side panel.
5. Select **"Done"**to complete the combination and another.
6. Select **"Save"**in the bottom right corner to complete floor plan edits

| **Please note**: All new combinations are available in-house by default. You'll log-in to the online [Resy Dashboard Service Settings](https://os.resy.com/portal/venues)using Chrome to update Availability for a new table to 'online' or 'walk-in' status on the shift. |

### **Create and Edit Table Combinations on Resy Dashboard**

1. Log on to the [Dashboard](https://os.resy.com/portal/login) using Chrome.
2. Click “Venue” from the left-hand menu options.
3. Click “Floor Plans”.
4. Click the pencil icon next to the floor plan to edit.
5. Once you are in Edit mode, tap the first table that is part of the Combination.
6. Once the first table is selected, press and hold the Command (Ctrl if you are using a Windows) button on your keyboard to select additional tables.
7. Select **"****Create** **Combo"** in the top-left once all tables in the combination have been selected.[[IMAGE: create-and-add-combination-tables__img03]]
8. Select the Table Type, and Min/Max seats for the combination.
9. Click **"****Save"** when done editing.
