# Custom Policies

You can make customizations to specific tables (i.e. custom Cancellation Policy, custom reservation names, custom turn times etc.) by creating a custom policy for them. 

**In this article:**

* [How to Create a Custom Policy](#part1)

---

### **How to Create a Custom Policy**

First, you'll log on to the [Dashboard](https://os.resy.com/portal) using Chrome.

1. Click **"Service"** from the left-hand menu options.
2. Click **"****Shift Settings"** from the drop-down menu options.
3. Click the three dots next to the shift you are adding the Custom Policy to.
4. Click "**Edit Shift"**.
5. Scroll to and select "**Step 5 Custom Policies**".
6. Click "**Customize Tables**". ***Note****: If you're customizing slots select "Customize Slots" instead.*
7. Select the checkbox next to the tables you are customizing. ***Note****: if you need different custom policies for different tables, do not select all of the tables together. You'll need to create separate custom policies for each of the different policies.*
8. Click "**Next, Customize Policies**".
9. Once you made your customizations on this page, click "**Save**".
10. Click "**Update Shift**" to save the changes.

***Please note****: You can create Custom Policies for a single day as well. Learn more about single day shift updates [here](https://helpdesk.resy.com/en_us/how-to-make-a-single-day-edit-in-the-dashboard-service-settings-rJf6bD7IO).*
