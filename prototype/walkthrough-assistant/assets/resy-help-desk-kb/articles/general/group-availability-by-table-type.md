# **Group Availability By Table Type**

Dining Experiences are driven by Custom Policies which can be on the recurring shift level or applied as a Single-Day Edit. Included in this article you’ll find instructions on how to set up Group Availability By Table Type on the Resy app. 

A few things to keep in mind:

* Anything not customized in “Step 5: Custom Policies” will appear in the regular inventory.
* If you're using a Customized Reservation name in “Step 4: Reservation Settings” in your shift setting, these will appear as grouped reservations like the Custom Policies Grouping.**More information is included later in this article.**

**Please note**: Notify appears in regular inventory at the top of the venue page. There is no way to set a Notify for a specific experience.

#### How to Set up Group Availability by Table Type:

1. Log in to the ResyOS Dashboard.
2. From the left-hand menu, click **“Service”**, then **“Shift Settings**” from the drop-down menu.
3. Locate the shift you’d like to edit. Then click the three dots and select**“Edit Shift”**.
4. Under “Step 4: Custom Policy”, click “Customize Tables” to create a new dining experience, or “Edit” on an existing one.[[IMAGE: group-availability-by-table-type__img01]]
5. Select the tables you’d like to group and click “Next”.
6. Give the experience a name. For example, “Tasting Menu”. [[IMAGE: group-availability-by-table-type__img02]]
7. Optional: Set any custom policies you want. (E.g., turn times, prepaid, cancellation fees, etc.)
8. Optional: Toggle on “Customize Reservation Content”. Customizing Reservation Contentis**recommended for this pilot**to make sure the experiences are shown as expected to guests in the Resy app. An explanation of each field is below:
* **About:**Not required, but **strongly recommended**. This short description will appear below the Reservation Name and above the booking bricks.
* **Need to Know, Menu Highlights:** Not required. These will only appear on the next step, in the booking flow.
* **Venue Images:** Not required but recommended. This will appear grouped with the Dining Experience and should be different from the default Venue Image.**[[IMAGE: group-availability-by-table-type__img03]]**

**Please note:**“Step 4: Reservation Settings” of your Shift Settingswill also impact your venue’s page layout.  

* If using *“*Customize Reservation Name*”* in Step 4 of your Shift Settings, you will see these reservations grouped in the same way that the “Custom Policy” reservations are grouped.
* If using *“*Use Table Type*”* in Step 4 of your Shift Settings, you will see these tables/reservations grouped towards the top of the venue page(this is how availability currently shows)and all tables with “Custom Policies” will be grouped below.
