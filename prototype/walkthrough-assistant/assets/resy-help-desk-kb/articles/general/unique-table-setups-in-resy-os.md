# Unique Seating Setups in Resy OS

If you have chef's counter, hibachi or community seating in your restaurant you may need to know the best way to reflect these seating arrangements on your floor plan. Below we'll explain how to do these unique table setups on your floor plan using table combinations. 

**In this article**:  

* [Chef's Counter/Hibachi/Community](#part1)

---

  

### Chef's Counter/Hibachi/Community

* Each **seat** at your counter/table will be equivalent to one **table** in ResyOS (1 seat = 1 table).
* You'll want to set the capacity for each individual seat (table) as Min=1, Max=1.
* Once your individual tables have been added, you'll then build out table combinations. The combinations are how your party sizes of 2+ will book seats next to each other.
* We recommend adding combinations as sequentially as possible (ex. all 2 tops, then all 3 tops, then all 4 tops, and so on) to best help the auto-assignment algorithm when reservations are added.

Example: 

| **Individual Seats (Tables) Min/Max = 1** | **2-top Combination Tables Min/Max = 2** | **3-top Combination Tables Min/Max = 3** |
| --- | --- | --- |
| Table 1 | Tables 1 + 2 | Tables 1 + 2 + 3 |
| Table 2 | Tables 2 + 3 | Tables 2 + 3 + 4 |
| Table 3 | Tables 3 + 4 |  |
| Table 4 |  |  |
