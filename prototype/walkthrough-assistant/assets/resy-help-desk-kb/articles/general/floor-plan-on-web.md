# Floor Plan Web Editor

1. This article provides instructions on how to build a Floor Plan using the web tool in the Resy Dashboard.

**In this article:**

* [How to create a Floor Plan on web](https://helpdesk.resy.com/en_us/floor-plan-on-web-SyTdJuBp9#part1)
* [How to edit an existing Floor Plan on web](https://helpdesk.resy.com/en_us/floor-plan-on-web-SyTdJuBp9#part2)

 

---

  

**Create a Floor Plan on the Resy Dashboard**

1. Log in to the [Resy Dashboard](https://os.resy.com/portal/venues) using your credentials.
2. Select "Venue" from the left-hand menu options.
3. Select “Floor Plans".
4. Click “New Floor Plan.”

[[IMAGE: floor-plan-on-web__img01]]

5. Click “Add Table” to build a new floor plan from scratch and enter the following details: 

1. Table ID: The Table ID must be unique (i.e., you can only have one table 20 on your floor plan). Tap the Table ID field to edit.
2. Table Type: The Table Type should reflect the actual seating type of the table (Dining, Bar, Patio, High Top).
3. Min/Max Seats: Input the minimum and maximum capacity for the party size that will be allowed to book and be assigned to this table.
4. Shape: Select the shape of your table

6. Click “Save” when finished.

  

[[IMAGE: floor-plan-on-web__img02]]

  

 

**Please note:**

* If you change the Table ID (Table Number) on existing tables, the existing reservations will become **unassigned**and will need to be manually re-assigned.
* If you unknowingly unassigned a reservation, you can revert the Table ID to the original ID and Reservations will be re-assigned to the original Table ID assignment.
* All new tables created will be available in-house by default.
* Log-in to the online [Resy Dashboard Service Settings](https://os.resy.com/portal/venues) using Chrome to update Availability for a new table to “online” or “walk-in” status on the shift.
* You must “Add” your Floor plan to the shift for it to be active. In order to activate or use the floor plan you create, you'll log in to the [Resy Dashboard Service Settings](https://os.resy.com/portal/venues) using Chrome to select the floor plan in the desired shift.
* You can use the Table Type as the Reservation Display Name or create a Custom Reservation Display Name in the [Resy Dashboard Service Settings](https://os.resy.com/portal/venues).

  

---

  

**Edit an existing Floor Plan**

1. Log in to the [Resy Dashboard](https://os.resy.com/portal/venues) using your credentials.
2. Click the restaurant name in the top left corner, then select “Service” from the drop-down menu.
3. Select “Floor Plans” tab to the right of “Shift Settings”.
4. Click the pencil icon to the left of the ellipses.
5. Click on the table you would like to make edits on.
6. From here, you can also duplicate your floor plan and add Décor Items.

  
[[IMAGE: floor-plan-on-web__img03]]

[[IMAGE: floor-plan-on-web__img04]][[IMAGE: floor-plan-on-web__img05]]

  

**Create and Edit Table Combinations**

1. Once you are in edit mode, tap the first table that is part of the combination.
2. Once the first table is selected, press and hold the “Command” (“Ctrl” if you are using a Windows) button on your keyboard to select additional tables.
3. Select “Create Combo” in the top left once all the tables in the combination have been selected.

  

[[IMAGE: floor-plan-on-web__img06]]

  

4. Select the Table Type, and Min/Max seats for the combination.

5. Click “Save” when done editing.
