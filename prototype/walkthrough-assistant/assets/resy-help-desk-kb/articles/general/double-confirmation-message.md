# Double Confirmation Message

Add a Double Confirmation Message that pops up when guests book specific tables or all reservations. This pop-up message can contain important  information that you'd like guests to confirm that they have read before they can complete booking their reservation. 

  

**Add Double Confirmation Message to All Reservations**

1. First, you'll log on to the [Dashboard](https://os.resy.com/portal/login) using Chrome.
2. Click **"Service"** from the left-hand menu options.
3. Click **"Shift Settings"** from the drop-down menu options.
4. Click the3 dots next to the shift you want to add the message to.
5. Click **"Edit Shift"**.
6. Go to "Step 4 Reservations Settings" and toggle on **"Double Confirmation Message"**.
7. Enter the verbiage you would like to appear in the pop-up message.
8. Click **"Update Shift"**.

**Add a Double Confirmation Message to Specific Tables**

1. First, you'll log on to the [Dashboard](https://os.resy.com/portal/login) using Chrome.
2. Click **"Service"** from the left-hand menu options.
3. Click **"Shift Settings"** from the drop-down menu options.
4. Click the3 dots next to the shift you want to add the message to.
5. Click **"Edit Shift"**.
6. Go to "Step 5 Custom Policies**"**.
7. Click either the pencil icon next to your current policy that you would like to edit or click **"Customize Tables"** to create a new policy.
8. Select the tables you would like the message to be applied to.
9. Click "Next, Customize Policies".
10. Scroll down and toggle on **"Double Confirmation Message"**.
11. Enter your verbiage.
12. Click **"Save"**.
13. Click **"Update Shift"**.
