# Reservation Names vs Table Type

An overview on the difference between displaying your Table Type name or a custom Reservation Name to guests when booking via [Resy.com](https://resy.com/) or the Resy app. 

In this article:

* [Table Type Name](#part1)
* [Custom Reservation Names](#part2)
	+ For All Reservations
	+ For Specific Tables
* [Table Settings for Indoor and Outdoor Seating Filter](#part3)

**Please note:** If you customize the reservation name, this only changes the name that guests see when booking. You'll see both the custom reservation name and table type name in ResyOS. For example, if you customize your Bar tables’ names to “Dinner” you'll see “Dinner (Bar)” in ResyOS and the guests will see “Dinner” when booking. 

### **Table Type Name**

If you want your guests to see the standard table type name that you've set on the floor plan in the ResyOS app, please follow the steps below:

1. Go to the [online dashboard](https://os.resy.com/portal/login).
2. Click "**Service**".
3. Click "**Shift Settings**".
4. Click the three dots next to your shift.
5. Select "**Edit Shift**".
6. Go to "**Step 4 Reservation Settings**".
7. Select "**Use table type:**"
8. Click "**Update Shift**".

### **Custom Reservation Names**

**For All Reservations**

If you'd like a custom reservation name to display for all your reservations when guests book, please follow the steps below:

1. Go to the [online dashboard](https://os.resy.com/portal/login).
2. Click "**Service**".
3. Click "**Shift Settings**".
4. Click the three dots next to your shift.
5. Select "**Edit Shift**".
6. Go to "**Step 4 Reservation Settings**".
7. Select "**Customize reservation name**".
8. Enter the reservation name.
9. Click "**Update Shift**".

[[IMAGE: reservation-names__img02]]  
  
  

**For Specific Tables**

If you'd like specific tables to display a custom name when guests book, please follow the steps below:

1. Go to the [online dashboard](https://os.resy.com/portal/login).Click the icon on the upper left.
2. Click "**Service**".
3. Click "**Shift Settings**".
4. Click the three dots next to your shift.
5. Select "**Edit Shift**".
6. Go to "**Step 5 Custom Policies**".
7. Click "**Customize Tables**".
8. Select the tables that you'd like to customize.
9. Click "**Next, Customize Policies**".
10. Enter the reservation name.
11. Click "**Save**".
12. Click "**Update Shift**".

### **Table Settings for Indoor and Outdoor Seating Filter**

**When your guests search for reservations on Resy.com or the Resy app using the Seating Filter, your Table Types can maximize visibility of Indoor and Outdoor tables.** 

When guests are searching for a reservation with the Seating Filter selected, the system will look at keywords on the list below to determine if your tables are Indoor or Outdoor.  

This is matched with the Table Type or Custom Policy’s Reservation Name on the reservation brick which is visible on resy.com or the Resy app. This includes both Table Type on Floor Plan and Custom Policy Names settings. 

For example, if the Table Type and/or Custom Policy Reservation Name includes the word "Patio", Resy will automatically show this in the "Outdoor" search results. Any Table Types/Custom Policies that do not contain any of the keywords in the Outdoor Keywords List in their name will default to "Indoor".  

Once a user selects a filter, they will only see reservation tiles that match for indoor or outdoor. If a venue has both indoor and outdoor availability and the guest filters for outdoor, they’ll only see restaurants with outdoor inventory and will only see those reservation types in the availability.  

**Please note:**The words "indoor" and "outdoor" work as an override. For example, "Indoor Patio" will still be classified as indoor. For unique seating offerings, such as “Enclosed Patio” or “Pool Hall”, we have an exceptions list to ensure this shows as indoor. Please reference the exceptions list for more examples.
