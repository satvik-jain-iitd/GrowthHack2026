# Fishbowl Integration

## Fishbowl Integration

The Resy x Fishbowl Integration requires a one-time setup to link the platforms. This self-guided setup takes place in your Fishbowl dashboard—all you need is your Resy Venue ID.

### Finding your Resy Venue ID:

1. Log in to your ResyOS Dashboard at: <https://os.resy.com/portal/login>.
2. In the menu on the left, select the “Venue” dropdown.
3. Select “Basic Info”.
4. Scroll down the page until you see Venue ID.
5. Record the number to the right of Venue ID.

### Mapping Resy Venue IDs to Fishbowl Stores:

*Please note: You will need to repeat these steps for each location you wish to connect.*

1. Log in to app.fishbowl.com.
	* Select the desired store
2. Click Connect Tab.
	* Select Integrations from submenu[[IMAGE: fishbowl-integration__img01]]
3. Select “Reservation” from left side panel to filer results.
	* Select the Resy tile[[IMAGE: fishbowl-integration__img02]]
4. Click the +New Connection button in upper right corner.  [[IMAGE: fishbowl-integration__img03]]
5. Enter a name that makes sense to you for the Connection in the Integration Name field. *We recommend as a best practice ["Venue Name" - Resy] to keep it simple and straightforward.*
6. Enter your Resy Venue ID in the Venue Name field.  
[[IMAGE: fishbowl-integration__img04]]
7. Click Add.
8. Successful Integrations are listed in the “Connections” section at the bottom of the screen.

### Troubleshooting and Offboarding

In the event your Resy connection is disconnected, the Fishbowl dashboard will show the status on the widget as “Interrupted”.

[[IMAGE: fishbowl-integration__img05]]

  

1. Click on the integration to view more details.
2. On the Connection Detail Page, users will be able to view sync history and status.
	* To disable an existing connection, swipe the toggle under State.
	* To delete an existing connection, click on the trash icon under Actions. *The user should see clear toast notifications confirming the success or failure of any attempts to enable or disable a connection. Please note that there are different levels of permissions that a user may have within Fishbowl. This may prevent the user from being able to perform certain actions.**[[IMAGE: fishbowl-integration__img06]]*
3. If data is not connected or set up properly, the panel will display a “No Results Found” message.

### Common Troubleshooting Solutions

1. Confirm Resy VenueID entered and re-enter key to retry connection.
2. If failures persist, escalate to Fishbowl Onboarding Manager or your Account Manager, or contact Support.

### Fishbowl Support Pathways

1. In the main menu, select the Help button at the bottom of the navigation bar.
	* This will allow the user to view the status of previously submitted tickets.
2. Select the + New Ticket button.
3. This will open a modal to submit a support request where the user can assign urgency level, attach screenshots or debug file, and provide detailed descriptions of the issue. Click on Submit to complete the ticket submission.
4. There is also a CTA available that takes the user to the Fishbowl knowledge base with helpful articles.

### Offboarding Steps

If your venue needs to offboard from Fishbowl, please initiate cancellation via the Fishbowl ticketing portal or reach out to the Account Manager.
