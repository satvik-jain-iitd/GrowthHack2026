# Resy Widget Installation

Below are instructions on adding the Resy booking widget to your restaurants website. 

In this article:

* [Bentobox](#part1)
* [Squarespace](#part2)
* [Wordpress](#part3)
* [Wix](#part4)
* [GoDaddy](#part5)

---

To access your widget code and view further instructions navigate to the widget page in the Resy dashboard by following these steps:

1. Access the [Resy Dashboard](http://os.resy.com/portal) using Chrome.
2. Click "Venue" from the left-hand menu options.
3. Click "Basic Info".
4. Scroll down to the "Widget" section.

For more detailed instructions on how to embed code into your website, please refer to your corresponding website builder’s help center.

### Widget Installation Instructions

**BENTOBOX**

BentoBox is integrated with Resy and does not require the full widget code. You only need the Venue ID & API Key. If you need additional assistance, please reach out to your BentoBox account manager.

1. Log in to your Bentobox Page: <https://getbento.com/login/>.
2. On the left-hand side of the page, click Integrations and scroll down to "Reservations".
3. If you have another reservation platform that is connected, disconnect that platform first.
4. Click “Connect” next to Resy.
5. Enter the following information (located on the widget page of the Resy Dashboard)
	1. API Key
	2. Venue IDS
6. Save and Close.

**SQUARESPACE**

1. Log in to your Squarespace Page: account.squarespace.com.
2. Navigate to the page you want to add the widget to.
3. Select the + at the insert point.
4. Select the option “Code Snippet” or “Code”.
5. Remove the sample code.
6. Paste in the Resy widget code.
7. Click “Apply”.
8. To preview the widget click --> Preview in Safe Mode or Save and navigate to your live website to test the widget.
9. Note: If the widget isn’t appearing unless you refresh on the page, please disable [Ajax loading](https://support.squarespace.com/hc/en-us/articles/115000253288).

**WORDPRESS**

Due to the many templates and customizations possible for WordPress, we're unable to provide step-by-step instructions. We recommend you review the documentation for your theme and follow the Alternate Widget Embedding Instructions located on the widget page of the Resy Dashboard.

**WIX**

Navigate to the widget page in the Resy dashboard and follow the steps under Alternate Widget Embedding Instructions.

**GODADDY**

Navigate to the widget page in the Resy dashboard and follow the steps under Alternate Widget Embedding Instructions.
