# Using Add-On Items to Offer Different Priced Event Tickets

You'll first need to create the add-on item for each ticket in the Item Library.  (For example, if you want to sell Adult and Children's tickets for an event, you'll need to create an "Adult Ticket" and "Children's Ticket" item, which can be priced appropriately.)

[Click here](https://helpdesk.resy.com/en_us/how-can-i-manage-add-on-items-S1vobw7UO) to view an article that explains how to add an Item to the Item Library.

In the [Online Dashboard](https://os.resy.com/portal/venues), 

1. Click "Events" from the left-hand menu to see your Event Management options.
2. Click "**Create Event**" or "**New Event**".
3. Select your event type and complete the step(s) until you get to **"****Ticket Settings"**.
4. InTicket Settings, click "**Create Ticket**" > enter the name > toggle on "**Prepaid**"with a set amount of $0.
5. Click the **"Items"** tab.
6. Click **"Start From Scratch"**. *Note: Recommend naming this "Select Your Ticket Price"*.
7. Under **"****Pricing"**, toggle on "Items are individually priced and added to the final cost".
8. Under **"****Booking Rules"**, toggle on "Require selection(s) for booking" and use "1 selection per guest".
9. Add the corresponding tickets from the Item Library, select "**Add to ticket**".
10. Click "**Edit Ticket**".
11. Complete the event details.
12. Click "**Schedule Event**".
