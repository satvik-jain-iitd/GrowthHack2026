# Manage a Special Event with Normal Service

Manage your special event and standard service in Resy with the event tool and setting table availability on your shifts.

**Please note**: In the Resy Dashboard you can create events that take over your entire space. You can also create events for specific sections, or tables, in your Dining Room. **This article will focus on how to build a special service, when you are also running normal service.** 

  

## **Creating your special service**

1. From the dashboard menu select **“Service”**.
2. Click **“Shift Settings”**.
3. Click the three dots next to the shifts you want to add this service to.
4. Click **“Edit Shift"**.
5. Navigate down to “Step 5 Custom Policies".
6. Click “Customize Tables” to select the specific tables you would like to be included in your event, then select “Next, Customize Policies".
7. You'll be able to add a custom table name and any other attributes specific to the table, including prepaid payment.

  
Please note: If you want this special service to be available to book online at specific times, click [here](https://resy.kustomer.help/en_us/how-to-manage-shift-availability-rJk3ZDQ8_) for more information on how to adjust the tables availability.
