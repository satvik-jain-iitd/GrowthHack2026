# How do I add Prepaid Items to an Event Ticket?

If you need assistance setting up your event, [this article](https://resy.kustomer.help/en_us/how-to-create-an-event-B1dKWDQUd) will help you get started!

You can add items to the event ticket. For example:

* Take-Home Item (e.g., Cookbook),
* Meal Enhancement (e.g., Beverage Pairing, Caviar)
* Add to the Experience (e.g., Bottle Service)

**How to create an Item for your event ticket:**

1. Select the event and tap the pencil icon to edit.
2. Select “Step 3” and the "Create Ticket" button or select the ticket and tap the pencil icon to edit.
3. Complete the required fields in the "Ticket" tab.
4. Click the “Items” tab.
5. Click the "Select from Library" button.
6. Click “Create Item".
7. Complete the required fields such as name, price, and [Item type](https://resy.kustomer.help/en_us/how-can-i-manage-add-on-items-S1vobw7UO).
8. Complete the optional fields such as description and image.
9. Choose [Inventory](https://resy.kustomer.help/en_us/how-can-i-manage-add-on-items-S1vobw7UO) options such as total inventory and daily limit.
10. Click "Add to Ticket", then "Create Ticket" to save.

**How to Add or Remove Items for your Event Ticket:**

1. Select the event and tap the pencil icon to edit.
2. Select “Step 3” and the “Create Ticket” button or select the ticket and tap the pencil icon to edit.
3. Click the "Items" tab.
4. Click the "Select from Library" button.
5. Select the "Item."
6. Click "Add to Ticket."
7. Click "Edit Ticket" to save.

**Please note**: Add-on Items are currently only available as a **Prepaid** option.
