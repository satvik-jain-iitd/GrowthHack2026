# Event Feature

Create and manage events with Resy to generate revenue and create unique culinary experiences for your guests. Create General Admissions events for things like backyard BBQs and NYE parties or choose Assigned Seating events for wine dinners and chef collaborations. Learn how to create, edit, cancel, and change events in the dashboard.

**In this article:**

* How to Create an Event
* Include a Service Fee
* How to Make an Event Private
* Preview your Event

---

## **How to Create an Event**

1. Log into the [Resy Dashboard](https://os.resy.com/portal/venues).
2. Click **“Events”** from the left-hand menu options.
3. Click into any of the **"Events"** drop-down options.
4. Click **"New Event"** or **“Create Event”** to get started with a new event.
5. If this is your first event with Resy, you'll only see the option to click “New Event”. If you have other upcoming or past Resy events, you'll see them listed on your Event Management pages where you can check your ticket sales, make event edits, and copy past events to create a new experience.
6. You'll be asked to choose the type of event you'd like to create. Follow the links at the bottom of the article for step-by-step instructions.

**Please note:**Events saved as a draft to be completed later may default to "This Event Will Run Alongside Normal Service in a Portion of my Restaurant", even if you selected "This Event Will Replace Normal Service". Before publishing your event, return to Step 1 of the event creation process, select the correct option, and then publish your event.

**A note about floor plans:**When setting up an event, you'll need to create a new floor plan with table numbers that are different from those on your other floor plans. This will prevent event pacing and availability from conflicting with your normal base shift pacing and availability.

## **Include a Service Fee**

You can add a service fee to paid Event Tickets.

**Please note**: The service fee amount is included in the ticket price amount. To indicate that a tax will be charged in addition to the ticket and service fee total, a + tax suffix is added.

                 For example: A $285 ticket with a $4.97 service fee will display as $289.97 + tax

To add a service fee to your prepaid Event Ticket, navigate to Ticket Settings in your event. Under the Ticket Policies section, toggle on the “Include service fee” option.  
   
Hover over the info (i) icon to display this message: "Several U.S. laws set requirements for the way fees are displayed to users searching for offerings on Resy. Consistent with these laws, effective October 29, 2024, the total price displayed on an offering will include the service fee amount."

## How to Make an Event Private

You'll now have the ability to:

* Hide an event on [resy.com](//resy.com) and make it accessible via link that is shared by venue.
* Change a public event that is already live to a Private Event.

**Please note:**The Private Event page can be accessed by anyone who has the link. For further privacy, you may consider an exclusive group if you're on the Platform 360 package.

**All events will be set as public by default. When creating a new event, you can adjust the toggle in Step 1 to set your event as public or private.**

### **To make your event private:**

1. Log into the [Resy Dashboard](https://os.resy.com/portal/venues)..
2. Click **“Events”** from the left-hand menu options.
3. Click into any of the **"Events"** drop-down options.
4. Click **"New Event"** or **“Create Event”** to get started with a new event.
5. You'll be asked to choose the type of event you'd like to create.
6. In Step 1, enter your Event Basics.
7. Use the toggle in "Is this event private?" to change if the event is public or private.
8. Click 'Next, Service Settings' in the bottom-right corner.
9. Follow the links at the bottom of the article for step-by-step instructions.

[[IMAGE: how-to-create-an-event__img03]]  

### Locating your Private Event link:

If the Private Event is Live, the event link can be copied from the Event Management page. 

1. Log into the [Resy Dashboard](https://os.resy.com/portal/venues).
2. Click **“Events”** from the left-hand menu options.
3. Click **"Live Events"**.
4. Navigate to the event and click "Copy Event Link" next to Live event title. This saves the event link to your Copy and Paste Clipboard. Or, to view the full link, click on the three dots on your live event and click "Privacy Settings". You can either view the link or copy it.

 [[IMAGE: how-to-create-an-event__img04]]

**If a Private Event is upcoming and not yet live, the private event link should be pulled from the Preview Event page.**

**Please note:**The private event link will not display the event page until the event goes live. 

1. Log into the [Resy Dashboard](https://os.resy.com/portal/venues).
2. Click **“Events”** from the left-hand menu options.
3. Click **"Drafts"**.
4. Click the three dots in the top-right corner of the desired upcoming event.
5. Select **"Preview Event"**.
6. Copy the full URL from your search bar.

Example Event Link**:**resy.com/cities/new-york-ny/venues/restaurant-name/events/2024-10-03

**Preview Your Event**

You'll have the ability to: 

* See a preview of how your event will appear to guests on the web and booking widget.
* Toggle between previewing the event and editing the event content.
* Generate a preview link that can be shared with others (i.e., managers for approval).

To preview your event:

1. Go to the **“Ticket Settings”**.
2. Create your Ticket Types.
3. Under "General Sales" enter the date and time you'd like the event to go live to guests.
4. Under "Off-Market Time" enter when you'd like booking for the event to go off-line.
5. From there, you will see “Preview” and “Save Draft” in blue on the bottom left-hand corner.

[[IMAGE: how-to-create-an-event__img06]]  

**Please note**: You'll be able to preview your event from any step once you've completed the Ticket Settings step. 

The first time you preview an event, you'll get a pop-up message that says to “Please save a draft before previewing”. After the first time this pop-up is received, selecting “Preview” will also automatically save the latest draft version of the event.

[[IMAGE: how-to-create-an-event__img07]] 

You can then click **"Save Draft & Preview"** and you'll be taken to a preview page of the event. 

  
[[IMAGE: how-to-create-an-event__img08]]

**Please note**: The preview page will need to be refreshed to see the most recently saved version of the draft event.  

Once on the preview page, you can click "Copy Preview Link" if you'd like to send a link to this preview page to a member of your staff to view before going live. The preview link is for**internal review purposes only** and will differ from the live event link. This link will not direct guests to the live event booking page.
