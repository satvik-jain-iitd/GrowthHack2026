# Responsive Border Utility Classes

Breakpoint-scoped border utilities from the `dls-max` stylesheet.

Available breakpoint suffixes: `-min-down`, `-xs-up`, `-xs-down`, `-sm-up`, `-sm-down`, `-md-up`, `-md-down`, `-lg-up`, `-lg-down`, `-xl-up`, `-xl-down`, `-max-up`

For static (non-responsive) border classes, see [utilities-borders.md](utilities-borders.md).
