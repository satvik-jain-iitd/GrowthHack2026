# Core Utility Classes — Index

All utility classes come from the `dls-core` stylesheet. This file is an index only — load the relevant sub-file for the full class list.

For responsive breakpoint utilities (`dls-max` stylesheet), see [utility-classes-extra.md](utility-classes-extra.md).

---

## Sub-files

| Category | File | Contents |
|---|---|---|
| Layout | [utilities-layout.md](utilities-layout.md) | Display, Flex, Grid, Float, Position, Scroll |
| Spacing | [utilities-spacing.md](utilities-spacing.md) | Margin, Padding, Stack |
| Typography | [utilities-typography.md](utilities-typography.md) | Body, Headings, Fonts, Font Weight, Text, Label, Links |
| Colors | [utilities-colors.md](utilities-colors.md) | Card, Cobrand, Data Viz, DLS Core, FICO, Filter, Foundation Tokens, Offers, Trend |

| Animation | [utilities-animation.md](utilities-animation.md) | Delay, Fade, Slide |
| Misc | [utilities-misc.md](utilities-misc.md) | Shadows, Gradients, Lists, Backgrounds, Visibility, Height/Width, Screen Reader, etc. |

---

## When to load each file

- **Building layouts or using flexbox/grid** → [utilities-layout.md](utilities-layout.md)
- **Adding margin, padding, or spacing between elements** → [utilities-spacing.md](utilities-spacing.md)
- **Styling text, headings, or fonts** → [utilities-typography.md](utilities-typography.md)
- **Applying color to text, backgrounds, or icons** → [utilities-colors.md](utilities-colors.md)
- **Adding or removing borders, or rounding corners** → [utilities-borders.md](utilities-borders.md)
- **Adding animations or transitions** → [utilities-animation.md](utilities-animation.md)
- **Shadows, gradients, visibility, screen reader, or other helpers** → [utilities-misc.md](utilities-misc.md)
