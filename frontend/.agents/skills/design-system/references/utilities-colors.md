# Color Utility Classes

Covers all color utilities from `dls-core`, organized by category.

Each color token comes in three forms:
- `<name>` — sets `color` (text)
- `<name>-bg` — sets `background-color`
- `<name>-bg-hvr` — sets `background-color` on hover
