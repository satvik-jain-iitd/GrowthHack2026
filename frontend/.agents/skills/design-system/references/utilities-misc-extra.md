# Responsive Visibility Utility Classes

Breakpoint-scoped visibility utilities from the `dls-max` stylesheet.

Available breakpoint suffixes: `-min-down`, `-xs-up`, `-xs-down`, `-sm-up`, `-sm-down`, `-md-up`, `-md-down`, `-lg-up`, `-lg-down`, `-xl-up`, `-xl-down`, `-max-up`

For static (non-responsive) visibility and misc classes, see [utilities-misc.md](utilities-misc.md).

---

- `visible-min-down` / `visible-xs-up` / `visible-xs-down` / `visible-sm-up` / `visible-sm-down` / `visible-md-up` / `visible-md-down` / `visible-lg-up` / `visible-lg-down` / `visible-xl-up` / `visible-xl-down` / `visible-max-up`
